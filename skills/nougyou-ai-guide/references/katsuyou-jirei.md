## 1. 農園AIエージェントを育てる（Claude / ChatGPT）

「農業×AIエージェント」連載 全13回。単発のチャット利用から、自律的に動く農園アシスタントへ育てる流れ。

### 育て方のステップ（連載の骨格）

| 段階 | やること | 記事 |
|------|---------|------|
| ①定時通知 | ChatGPT Tasksで毎朝の情報収集を自動化 | vol2 |
| ②自分ごと化 | 一般論ではなく「自分の圃場・品目にどう影響するか」まで書かせる | vol3 |
| ③記憶を持たせる | `my-farm/` フォルダと `CLAUDE.md` に農園の前提情報を置く | vol6・vol7 |
| ④経験を貯める | 栽培日誌を蓄積し、年をまたいで比較できる相談相手にする | vol8 |
| ⑤自動巡回 | スケジューラーで「毎週金曜7時に調べて要約」を自走させる | vol9〜11 |
| ⑥どこからでも指示 | Dispatchで畑からスマホ経由でPC作業を依頼 | vol12 |

### 個別事例

**毎朝6時の自動情報収集**（vol2）
- 課題：天気・相場・補助金情報を毎朝自分で探しに行く手間
- ツール：ChatGPT Tasks（有料プラン 月約3,000円）
- 結果：定時タスクを登録すると毎朝6時にスマホへ通知が届く
- 記事の勧め方が誠実：「1ヶ月お試しで、合わなければ解約」

**"うちの事情"を覚えさせる**（vol6・vol7）
- 課題：毎回「うちの品目・地域・規模」を説明し直すのが面倒。チャットが「肥料相談」「病害虫」「出荷計画」と分散する
- ツール：Claude Pro（月約3,000円）＋ `my-farm/` フォルダ＋ `CLAUDE.md`
- やったこと：作業フォルダを指定し、チャットで `@CLAUDE.md` を読み込ませて前提を毎回ロード
- 結果：専属アドバイザーのような相談体験に変わった

**データを"経験"に変える**（vol8）
- キーメッセージ：「データは1年で腐る。でもAIに渡せば"経験"になる」
- 栽培日誌を蓄積して年次比較させると「2年目のAIは1年目とは別物になる」

**寝ている間の自動巡回**（vol9〜11）
- ツール：Claude Cowork スケジューラー（設定3分）
- やったこと：「毎週金曜の朝7時にこれをやって」で調査→要約→ファイル書き出しまで自動化
- 落とし穴：Desktop版はPCが起動＋アプリ起動中のみ動作（vol10）。Cloudタスクなら PCを閉じても動く（vol11）

**畑からPC作業を依頼**（vol12）
- 課題：出荷伝票のExcel入力・写真整理・メール下書きは、スマホ検索では片付かない
- ツール：Claude の Dispatch機能（QRコード読み取りのみ、セットアップ10分）
- 結果：畑や市場からスマホで指示 → PCのClaudeが作業 → 結果がスマホに返る
- 定時（Cloudタスク）＋オンデマンド（Dispatch）の組み合わせで24時間依頼可能に

### AIによる自律栽培実験「Project Sol」

- 2025年11月開始、Anthropicの公開実験。Claudeがトマト「Sol」の栽培環境を100日間完全自律制御
- センサー13種（温度×3、湿度×2、土壌水分×2、土壌温度×2、CO2、葉温、粒子状物質、カメラ）
- 15分〜2時間ごとにセンサーデータを確認して制御判断
- 構造：**Sense → Think → Act → Log** のループ
- 落とし穴3つ：センサー値の信頼性／制御のやりすぎ／障害時の対応
- **農業的な意味**：決まった時刻に水を出すタイマーではなく、「土の湿り具合を見てから水をやる」という農家の判断そのものをAIが担った点が従来の自動灌水と決定的に違う

## 2. フィジカルAI（畑で動くロボット）

「フィジカルAI」連載 全8回。生成AIに「手足」がついた段階の技術。

### 概念の整理（vol1・vol2）

- **定義**：プログラム通りに動くのではなく「自分で見て・考えて・判断する」
- **3段階モデル**：①電話で肥料を注文 → ②注文・配送が自動 → ③AIが畑に来て撒く
- **エッジAI**：ロボット本体にAIを搭載。通信なしでその場で判断できる＝「電話で指示を仰がず自分の頭で動く」
- **LiDAR**：レーザーで形を測る＝「触って確かめる感覚」。カメラと併用すると雑草と作物の高さの違いが分かる
- **デジタルツイン**：「牧場物語」のように、自分の畑と同条件のデータ上で試し運営する
- **自動運転レベル**：L1＝カーナビが道を教える／L2＝監視者が横に座るタクシー／L3＝完全無人タクシー
- **VLA（Vision-Language-Action）モデル**：「赤い実だけ取って」という言葉が通じるようになる技術

### 国産メーカーの現在地（vol4）

| メーカー | 取り組み | ポイント |
|---------|---------|---------|
| クボタ | 水素FC×無人トラクタ（万博で世界初コンセプト） | 100馬力級・半日連続稼働。前後左右のLiDAR＋AIカメラで人/車/障害物を識別し回避。圃場間の公道移動も自動、5G遠隔監視。既存アグリロボ販売は前年比50%増 |
| ヤンマー | コンバインの「隅刈り」自動化 | 最大の難所を2周目から全自動化し、技能差を解消 |
| 井関農機 | 直進アシストを中型コンバインに初搭載 | 2,000万円超の大型機限定だった機能を1,410万円〜に降ろした |

連載のメッセージ：**「完璧な自律型AIを待つ必要はない」**

### AIピンポイント散布（vol5）

- John Deere「See & Spray」：**36台のAIカメラ**が圃場を高速スキャン、ディープラーニングで作物と雑草を識別し雑草だけに噴射
- 2025年実績：**500万エーカー**（東京都の約94倍）に適用、除草剤**平均50%削減**、**3,100万ガロン**を節約
- 対応作物はトウモロコシ・大豆・綿花・小麦。日本の水稲・果樹は未対応

### なぜ農業のAI導入は難しいのか（vol6）

農業が「AIにとって最も難しい仕事」である5つの壁：

1. **天候** — 雨・泥
2. **不整地** — 傾斜地
3. **通信制約** — 圃場にWi-Fiがない
4. **個体差** — 工場の部品と違い、作物は一つ一つ違う
5. **安全・規制** — 人や動物と共有する開放空間で動く

※ 発信素材を作るとき、この「課題回」の視点を必ず入れる。良い面だけ並べた話は農家に信用されない。

## 3. 農家の実践ストーリー（モード②の素材）

実在の農家・農園の事例。**発信素材に使うときは必ず本人・記事にあたって裏を取ること。**
特に所在地・規模・数字は誤りが失礼にあたるため、記憶ではなく出典で確認する。

### 冨安 寛樹さん｜WFPダチョウファーム（北海道 平取町・むかわ町）

- **品目・規模**：ブロッコリー、大豆、カボチャ、ネギなど複数品目／約100haを管理
- **課題**：プログラミング経験ゼロ。作業記録はLINEグループでやりとりし、「畑から帰ってきてから、疲れた体で記憶を頼りにパソコンに入力する」状態。商用の農業IoTは月額数千〜数万円で導入しづらい
- **きっかけ**：大塚あみ氏の書籍『#100日チャレンジ』に触発され、2025年冬にPython独学からスタート
- **使ったツール**：ChatGPT Pro／Claude Pro／Gemini Advanced（3つ同時契約）、Python、React、Supabase、SwitchBot温湿度計プロ、Cloudflare、LINE、Airtable
- **やったこと**：
  - 100日チャレンジで毎日アプリを作って公開。未経験のReact・SupabaseもAIに聞きながら構築
  - ビニールハウス温度モニタリングをDIY（SwitchBot × Cloudflare × LINE）。乾電池式で配線不要、約50mのハウスでもBluetooth接続に問題なし
  - Airtable × LINE連携。メンバーはDBを意識せずLINEから入力→裏で自動整理
- **結果**：温度モニタリングは**初期投資約7,000円／月額0円**。自作なのでいつでも機能追加・変更できる
- **姿勢**：「1つのAIを信じすぎない」。リスクのある作業では複数AIに相談し、回答を突き合わせてから実行
- 記事：`tomiyasu-ai-interview-vol1`〜`vol3`（全4回、vol4は要確認）

### 川上 哲也さん｜川上牧場（酪農・乳牛約80頭／所在地は要確認）

- **きっかけ**：2023年2月、話題のChatGPTを「無料で使える」ことから「とりあえず触ってみよう」と開始。周囲にAIを使う酪農家はほぼいなかった。音声配信で「有料版の方が精度が良い」と聞き、2023年4月に課金を決断

- **結果**：確定申告の伝票整理が**丸1日 → 20〜30分**に短縮

### ストーリーに共通する型

事例を記事化するときの骨格として使える共通パターン：

1. **入口は「無料」か「とりあえず触ってみる」** — 最初から本格導入した人はいない
2. **有料化は具体的な不満がきっかけ** — 「精度が足りない」と感じた時点で課金を判断している
3. **最初の成果は"事務作業"に出る** — 栽培そのものより、記帳・マニュアル・議事録から効果が出る
4. **AIを信用しきらない姿勢を全員が持っている** — 「信頼するが、信用しない」「1つのAIを信じすぎない」
5. **目的は人に向かう** — 「人と向き合う時間を増やす」「未経験者に伝わるマニュアル」

## 4. 農家の"普段の仕事"で使う（実務テンプレ）

農業従事者100人調査では、**AI活用用途の1位は「記録・書類・事務作業」（48人）**。
派手な栽培AIより、まずここから入るのが現実的。

### 経理・確定申告

- **勘定科目の振り分け**：プロンプト例「私は個人で農業を営んでいます。[経費の内容]は確定申告でどの勘定科目に分類すればよいですか？」
  - **コツ**：「農業で使う」ではなく「米栽培で使う」「出荷用に使う」と具体化すると精度が上がる
- **毎日5分の記帳習慣**：スマホの音声でAIに話すだけで記帳。週1で見直し、最終確認は税理士
- **前提として必ず伝えること**：AIは「優秀なアシスタント」。**結果は8割正解、必ず検証が必要**
- **事前整理で税理士との打合せ時間が短縮でき、顧問料の節約につながる**
- **安全ルール**：学習に使われるAIにマイナンバーなどの個人情報を入れない
- 関連記事：`ai-accounting-faq-10`／`expense-account-ai-template`／`bookkeeping-ai-habit`／`ai-ok-ng-tax-check`

### 事業計画・経営判断（新規就農×AI 連載）

- **事業計画を組み立てる3ステップ**：**骨子 → 肉付け → チェック**
  - 出力構成：①経営の現状（3〜4行）②課題と解決策（3〜4行）③事業計画の概要（何を・いつまでに・いくらで）④期待される効果（数字で）⑤資金計画（自己資金＋補助金＋融資の内訳）
  - **注意**：売上予測・経費見積もりはAIの数字をそのまま使わない。提出前に**最低15分**のチェックリスト照合。行政書士・税理士の代替にはならない
- **経費率の比較**：農水省「営農類型別経営統計」の数字をAIに渡し、全国平均と自分の立ち位置を比較。就農1〜3年目は比較対象がないまま経営判断しがち、という課題認識が出発点
- **農機・ハウスの投資判断**：AIに機種情報を渡して**買う／リース／中古の3パターン総コスト比較表**を出力。見積の本体価格だけでは、減価償却・維持費・補助金で5年後の総コストが変わる
- **損益分岐点の試算**：米の概算金を15,000／18,000／21,000／24,000円の4水準で損益表を作り、分岐点を算出。「分岐点を1,000円下げるのに必要な費用削減額・単収増」まで逆算
  - **要点**：AIは価格を予測する道具ではなく、**「価格ごとに備える」道具**
- 関連記事：`new-farmer-ai-vol2`／`vol7`／`vol8`／`vol9`／`rice-price-2026-breakeven-ai`

### 販促・直売所

- **直売所POPを無料で作る（約5分）**：イラスト生成 → POPデザイン化 → 印刷の3ステップ
  - 画像プロンプト例：「水滴がついた真っ赤なトマト、淡い背景、手書き風」
  - 出力形式の指定：キャッチコピー15文字以内／説明文50〜80字／価格＋一言。**3パターン（感情訴求・事実／数字・問いかけ型）**を出させる
  - 課題認識：「同じ野菜でも、あの人のだけ売れる」「価格だけで比較される」
- **お礼状・同梱チラシ**：お礼状200〜300字（季節の挨拶＋畑の様子）、同梱チラシは保存方法・食べ方・レシピの3セクション
  - **作成10分、1件あたりの手間は約10秒**（署名だけ手書き）。春夏秋冬4パターンで1年使い回せる
- 関連記事：`direct-sales-pop-ai`／`ai-thankyou-letter`／`new-farmer-ai-vol5`／`nanobanana2-prompt-campaign`

### 病害虫診断・記録

- **写真で病害虫診断（約3分）**：ChatGPTに写真を添付し、病害虫候補・緊急度・対処法を出させる
  - プロンプト構成：役割「あなたは農業の病害虫診断をサポートする専門家」＋基本情報（作物名・栽培環境・発見場所）＋症状詳細（発症時期・広がり具合）
  - **必ず添える注意**：最終判断と農薬選定は普及員・JAへ確認する
  - コツ：葉のアップ＋全体写真の2枚を渡す。粘着板の害虫カウントにも使える
- **栽培日誌が続かない問題**：音声で話すだけの「AI3分記録術」。農薬名・品種名は聞き間違いがあるため要確認
- 関連記事：`pest-diagnosis-ai`／`ai-image-analysis-guide`／`farm-report`

### 無料で始める入口

- **Google AI Studio**：無料。プロンプト例「この野菜の特徴を活かしたPOPキャッチコピーを5つ」／競合直売所のチラシを渡して良い点・改善点を分析
- **Nano Banana 2**：Googleアカウントがあれば完全無料。農家向けテンプレートは`[ ]`を書き換えてペーストするだけ
- 関連記事：`ai-studio-for-farmer`／`nano-banana-pro-flyer`／`nano-banana-pro-photo`
